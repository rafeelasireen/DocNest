# Docnest

\# DocNest



\*\*AI-Powered Document Management and Intelligent Chat System\*\*



DocNest is an AI-powered document management application that helps users upload, process, understand, and interact with their documents using intelligent search and AI-generated responses.



\## Features



\- \*\*Document Upload:\*\* Upload and manage documents through a web interface.

\- \*\*AI Summarization:\*\* Generate summaries of uploaded documents.

\- \*\*Intelligent Chat:\*\* Ask questions about documents and receive AI-generated answers.

\- \*\*Semantic Search:\*\* Retrieve relevant information using vector embeddings.

\- \*\*Document Processing:\*\* Extract and process document content for analysis.

\- \*\*Web Interface:\*\* Access document features through a user-friendly frontend.



\## Technology Stack



\- \*\*Frontend:\*\* React / Vite

\- \*\*Backend:\*\* Python, FastAPI

\- \*\*Database:\*\* PostgreSQL

\- \*\*Vector Database:\*\* ChromaDB

\- \*\*AI / LLM:\*\* Ollama

\- \*\*Embeddings:\*\* Nomic Embed Text

\- \*\*Containerization:\*\* Docker and Docker Compose



\## Getting Started



\### Prerequisites



Install Docker Desktop and Git before starting the application.



\### Installation



&#x20;Navigate to the project directory:



&#x20;  ```bash

&#x20;  cd DocNest

&#x20;  ```



&#x20;Start the application using Docker Compose:



&#x20;  ```bash

&#x20;  docker compose up -d --build

&#x20;  ```



&#x20;Open the frontend in your browser:



&#x20;  http://localhost:5173



&#x20;The backend API is available at:



&#x20;  http://localhost:8000



\## Environment Configuration



Configure the environment variables required by the application before starting the services. Refer to the project's configuration files and ensure credentials and secrets are not committed to GitHub.
